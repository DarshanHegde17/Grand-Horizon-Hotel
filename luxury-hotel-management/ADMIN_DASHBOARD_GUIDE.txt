┌───────────────────────────────────────────────────────────────────────────┐
│                        CONFIRM ORDER WORKFLOW                             │
└───────────────────────────────────────────────────────────────────────────┘

STEP 1: User Books Room
  ┌─────────────────────────────────────┐
  │ User completes booking              │
  │ Status: "Confirmed"                 │
  │ Appears in: Order Summary           │
  └─────────────────────────────────────┘
            │
            ▼
STEP 2: Admin Sees in Order Summary
  ┌─────────────────────────────────────┐
  │ Admin opens "Order Summary" tab     │
  │ Order appears in:                   │
  │  • Today's Orders (if today)        │
  │  • Pending Orders (always)          │
  └─────────────────────────────────────┘
            │
            ▼
STEP 3: Admin Reviews Order
  ┌─────────────────────────────────────┐
  │ Check guest details                 │
  │ Verify room and dates               │
  │ Confirm amount                      │
  └─────────────────────────────────────┘
            │
            ▼
STEP 4: Admin Clicks "Confirm & Move to History"
  ┌─────────────────────────────────────┐
  │ Button clicked                      │
  │ API call: PUT /bookings/:id/status  │
  │ Body: { status: "Completed" }       │
  └─────────────────────────────────────┘
            │
            ▼
STEP 5: Order Moves to History
  ┌─────────────────────────────────────┐
  │ Status: "Completed"                 │
  │ Removed from: Order Summary         │
  │ Added to: Order History             │
  │ Grouped by: Creation date           │
  │ Success notification shown          │
  └─────────────────────────────────────┘

TAB                  | PURPOSE                        | KEY FEATURE
─────────────────────┼────────────────────────────────┼─────────────────────
📋 Overview          │ View all bookings in table     │ Search & filter
📊 Order Summary ⭐  │ Manage pending orders          │ Confirm button
📅 Order History ⭐  │ View past orders by date       │ Day-by-day grouping


STATUS COLORS:
  🟢 Confirmed  - Green  (needs confirmation)
  ⚫ Completed  - Grey   (confirmed/done)
  🔴 Cancelled  - Red    (cancelled)


BUTTONS:
  [✓ Confirm & Move to History]  - Changes status to "Completed"
  [Clear]                         - Clears search filters
  [Search]                        - Filters bookings


NAVIGATION:
  1. Login as admin → http://localhost:3000/admin/login
  2. Auto-redirects to Admin Dashboard
  3. Click tabs to switch views
  4. Statistics always visible at top
